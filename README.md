# 사이버캡 셰어 (Cybercab Share)

테슬라 사이버캡 같은 자율주행차의 **유휴 시간을 로보택시로 공유**해 수익을 내는 플랫폼의 웹 데모입니다.
카카오T 스타일의 승객 화면과 차주(오너) 대시보드를 한 페이지에서 오가며 볼 수 있고, 지도는 **실제 카카오맵 JavaScript SDK**로 부산 기장군 정관읍 일대를 그립니다.

- 배포 주소: **https://luke7851-soungouk.github.io/cybercab-share/** (GitHub Pages, `main` / root)
- 카카오 앱: `사이버캡 공유` (앱 ID 1650269) · JavaScript 키는 `app.js` 12행에 있습니다.
- 카카오 개발자센터에 `https://luke7851-soungouk.github.io` 웹 도메인이 등록되어 있어야 지도가 표시됩니다.

## 무엇이 실제인가

| 항목 | 구현 |
| --- | --- |
| 지도 | 카카오맵 JS SDK (`dapi.kakao.com/v2/maps/sdk.js`), 일반지도 ↔ 스카이뷰 전환, 확대·축소·드래그 |
| 지도 회전 | 360도 회전(45도 버튼·나침반 0도 복귀·두 손가락 비틀기·Shift+드래그). 지도 컨테이너를 150% 크기로 키워 돌리므로 어떤 각도에서도 모서리가 비지 않고, 차량 도착 배지·목적지 핀은 역회전해 똑바로 보입니다. 회전 중에는 드래그·휠·핀치를 회전 각도에 맞춰 직접 처리합니다. |
| 승차 지점 | 정관읍 중앙공원 `35.322678, 129.180878` |
| 주변 차량 5대 | 실제 위·경도 위에서 정관읍 도로를 따라 이동하는 `CustomOverlay`. 탭하면 차량 정보 팝업 |
| 경로 | `kakao.maps.Polyline` 실주행 경로 + `setBounds` 자동 맞춤 |
| 추천 목적지 7곳 | 기장역·오시리아·센텀시티·해운대·광안리·부산역·김해공항. 거리/시간은 OSRM 실주행 측정값(`routes.js`) |
| 장소 검색 | `kakao.maps.services.Places` 키워드 검색 → 검색한 곳을 목적지로 지정 |
| 요금 | 실거리 × km 요금 + 기본요금, 차량 옵션 3종 배수, 3,000원 쿠폰 |
| 차주 모드 | 유휴 시간대, 수익 운행 ON/OFF, 배터리 복귀 기준, 운행 반경, 수수료 15% 제외 순수익 |

## 실행

```bash
python3 -m http.server 8000     # 이 폴더에서
# http://localhost:8000
```

## 카카오 JavaScript 키 넣기

키가 없으면 앱은 지도 자리에 안내 패널을 띄우고, 나머지 기능(목적지·옵션·결제·차주 모드)은 그대로 동작합니다.

1. [카카오 개발자센터](https://developers.kakao.com) → 내 애플리케이션 → 앱 선택 → **앱 키 → JavaScript 키** 복사
2. **플랫폼 → Web** 에 사이트 도메인 등록
   - `https://luke7851-soungouk.github.io`
   - 로컬 테스트용 `http://localhost:8000`
   (등록하지 않으면 지도 타일이 뜨지 않습니다.)
3. 키를 넣는 세 가지 방법
   - `app.js` 상단 `const KAKAO_JS_KEY = "..."` 에 붙여넣기
   - 배포 주소 뒤에 `?key=발급받은키` 로 한 번 열기 (브라우저에 저장됨)
   - 지도 안내 패널에 붙여넣고 **저장** (브라우저에만 저장)

JavaScript 키는 원래 웹에 노출되는 공개 값이며, 카카오는 **등록된 도메인에서만** 그 키를 쓰도록 제한합니다.

## 파일

```
index.html   화면 구조
app.css      카카오T 스타일 UI + 지도 오버레이 스타일
app.js       앱 로직 (카카오맵·경로·요금·배차·차주 대시보드)
routes.js    실주행 경로 데이터 (OSRM/OpenStreetMap, 2026-11-14 생성)
```

`routes.js` 는 `tools/fetch_routes.py` 로 다시 만들 수 있습니다(정관읍 기준).

## 지도 360도 회전 (2026-11-14)

카카오맵 JavaScript SDK 의 지도는 래스터 타일이라 bearing(회전) API 가 없습니다. 그래서 **지도 컨테이너를 CSS 로 돌리고**, 그 위에 얹히는 DOM 마커만 역회전하는 방식으로 구현했습니다.

- **컨트롤**: 지도 오른쪽 컨트롤 바의 `↺` `↻` (45도씩), 가운데 나침반(`45°`)을 탭하면 정북(0°)으로 가장 짧은 방향으로 부드럽게 복귀. 나침반 바늘은 화면 기준 진북을 가리킵니다. 현재 각도가 숫자로 표시됩니다.
- **모바일 두 손가락 비틀기**: `atan2` 로 두 손가락 각도 변화를 읽어 360도 자유 회전(손가락 떨림 방지를 위해 4도 이상 비틀 때 시작). 손가락을 벌리거나 오므리면 확대·축소(회전 중에는 CSS 배율로 미리 보여 주고 손을 띄면 지도 레벨에 반영).
- **데스크톱**: `Shift + 드래그` 로 회전, 회전 중에는 마우스 휠로 커서 지점 기준 줌.
- **모서리 빈 곳 없음**: 지도 레이어를 화면 대각선 길이(`√(W²+H²)`)의 정사각형으로 키워 중앙 정렬 → 45/90/180/270도 어디서도 흰 삼각형이 생기지 않습니다. 창 크기가 바뀌면 다시 계산합니다.
- **마커 역회전**: 차량 도착 배지(`2분`)·목적지 핀·라벨은 `rotate(-angle)` 로 역회전해 화면에서 똑바로 읽힙니다. 차량 본체는 도로 방향을 따라야 하므로 지도와 함께 돕니다.
- **드래그·줌 방향 보정**: 회전 중에는 카카오맵 기본 드래그·휠·핀치를 끄고 화면 좌표를 회전 각도만큼 되돌려 직접 팬·줌을 처리합니다(래스터 회전 상태에서 SDK 가 좌표를 화면 기준으로 되돌리지 못해 생기는 어긋남 방지).
- **경로 자동 맞춤**: 회전 각도를 반영한 화면 bbox 로 레벨·중심을 계산해, 회전한 상태에서도 경로가 시트 위 가시 영역 안에 들어옵니다.

## 동작 확인 (2026-11-14, 배포본 실측)

- 지도 타일·라벨 정상 표시, 일반지도 ↔ 스카이뷰 전환 확인(스카이뷰도 회전·역회전 마커 정상)
- 지도 360도 회전: ↺/↻ 45도 버튼, 나침반 탭 시 0도(정북) 부드러운 복귀, 45/90/180/270도에서 모서리 빈 곳 없음, 차량 배지·목적지 핀 역회전 확인
- 회전 상태 드래그 방향 검증: 90도 회전에서 화면 +120px 드래그 → 지도 콘텐츠 +121px 이동(대각 어긋남 없음)
- 두 손가락 제스처 검증: 33.7도 비틀기 → 지도 21.2도 회전(4도 데드존 이후), 벌리기 1.45배 → 지도 레벨 9→8 반영·복귀 시 배율 초기화
- "크게 보기"·차량 매칭 화면에서도 회전 상태 그대로 지도가 화면을 다 덮고 경로·마커 정상
- 정관읍 도로 위 사이버캡 5대가 초당 실제 속도(22~34km/h)로 이동, 탭하면 차량 팝업(번호·배터리·평점·좌표)
